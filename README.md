
# ProPass

Локальный SOCKS5-прокси с фрагментацией TLS ClientHello.

## Сборка APK

APK собирается автоматически через GitHub Actions.

1. Перейдите во вкладку **Actions**.
2. Дождитесь завершения сборки (10–20 минут).
3. Скачайте APK из раздела **Artifacts** (файл `propass-apk-arm64`).

## Использование

1. Установите APK на телефон.
2. Запустите ProPass.
3. Нажмите **Старт** (по умолчанию `127.0.0.1:1080`).
4. В настройках нужного приложения укажите SOCKS5-прокси `127.0.0.1:1080`.

## Архитектура

Сборка только под **arm64-v8a** (64-бит).
