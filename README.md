# Plum VPN

**Plum VPN** — это нативное приложение для Android, которое перехватывает весь системный трафик и обходит блокировки с помощью фрагментации TLS. Работает по принципу ByeByeDPI.

## 🚀 Возможности
- **Глобальный перехват:** Создает системный VPN-туннель (запрашивает разрешение при запуске).
- **Обход DPI:** Разрезает пакеты TLS ClientHello на части, чтобы системы глубокого анализа трафика не могли распознать, какой сайт вы открываете.
- **Автономность:** Работает в фоне и не требует настройки прокси в каждом отдельном приложении.
- **Стильный интерфейс:** Черная тема, жирный шрифт и оригинальная анимация.

## 🛠️ Сборка
Проект собирается автоматически в облаке GitHub.
1. Перейдите во вкладку **Actions**.
2. Выберите **Build Native VPN APK**.
3. Нажмите **Run workflow**.
4. Дождитесь окончания сборки и скачайте APK-файл из раздела **Artifacts**.

## 📲 Установка и использование
1. Установите APK на телефон.
2. Откройте приложение Plum VPN.
3. Нажмите кнопку **Включить VPN**.
4. В появившемся системном окне Android разрешите создание VPN-подключения.
5. Готово! Теперь весь трафик вашего телефона защищен от блокировок по домену (SNI).

## ⚠️ Ограничения
Приложение использует протокол TCP для фрагментации. UDP-трафик (например, звонки в Telegram или видео в YouTube по QUIC) может не обходить блокировки. Для максимальной совместимости рекомендуется отключить QUIC в настройках браузера.
